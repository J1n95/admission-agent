# 录取参照 · Admission Reference

面向香港、新加坡授课型硕士申请的 Windows 桌面 Agent。申请人用少量信息描述本科背景和申请方向，系统筛选项目，结合本地项目资料与已审核的公开成功案例，给出匹配理由、证据对照和申请材料建议。

**这是申请决策辅助原型，不是录取率计算器。** 页面上的百分比是未经真实录取/拒录结果校准的模型参考值，不能作为保底承诺；项目资料是本地快照，实际申请条件以学校官网为准。

## 产品做什么

1. **少量输入，筛选项目**：填写本科院校、专业、官方成绩、语言总分和可选经历，限定地区、学校与方向。
2. **读证据，解释匹配**：将申请背景与项目资料、审核后的公开成功案例对照；案例少或资料不足时显示不确定性，不把成功案例最低分当作录取门槛。
3. **辅助决定申请组合**：展示单项目分析和跨项目排序，并给出 CV/PS 可补强的方向。排序与百分比都只是模型参考，申请人仍需自行核实和决策。

## 两条 Agent 流程

```text
公开案例网页 → 采集与字段抽取 → 去重、校验及审核 → 本地案例库
                                                ↓
申请人简表 → 项目候选筛选 → 官方资料与已审核案例检索
                              → 单项目分析 → 跨项目比较 → 报告
```

采集 Agent 负责寻找和抽取公开案例，不直接判断申请人的录取机会；申请分析 Agent 才使用审核后的案例和项目资料。检索以结构化字段与证据排序为主，向量检索是可选能力，不是当前结果的必要前提。模型输出还需经过格式、引用和证据边界校验；**通过结构校验不等于事实正确或概率准确**。

## 已做的验证与仍未解决的问题

- 使用六份合成申请背景（金融、传媒、法律、公共卫生、教育、心理）完成 24 次 DeepSeek Flash 调用，覆盖项目筛选、单项目分析和跨项目排序。首次结构验收 23/24；修正本地否定句校验误报后，用保存的原始响应离线复核为 24/24。后者是**校验器修复**，不是模型能力提升。详见[复测记录](docs/cross-discipline-eval-2026-10-18.md)。
- 近期同条件院校背景对照发现：模型能读取已核验的院校层次和均分比较数据，但单项目百分比的跨院校顺序仍不稳定。当前不能声称“不同学校的录取机会已可靠排序”或“所有专业方向都已验收”。
- 尚无真实录取/拒录结果用于校准百分比，也未逐条复核全部项目资料与模型引用；语言只比较已收录的考试**总分**，不判断单项分数。完整申请要求仍须到官网核对。

## 下载与使用

目前公开的下载包是 [v0.1.14 Windows ZIP](https://github.com/J1n95/admission-agent/releases/tag/v0.1.14)；本机后续修复与试验尚未进入该公开包。解压后运行 `录取参照.exe`，无需安装 Node.js。首次使用需要自行配置兼容 OpenAI Chat Completions 的 HTTPS 接口、模型名称和 API Key，并可先测试连接。ZIP 未签名，Windows 可能显示来源提醒。

分析会把申请资料和相关证据发送给用户所选的模型服务商，调用费用由其账户承担。API Key 加密保存在本机 Windows 用户配置目录；申请记录与反馈也保存在本机，可在程序中删除，但无法撤回已经发给模型服务商的数据。请勿把个人 API Key 或真实申请资料放进截图、Issue 和公开仓库。

同一个 EXE 中也有“案例采集与审核”入口。可指定项目或按地区、学校、方向缩小范围；采集会访问外部网页并可能调用模型 API，新案例须通过审核才进入分析证据库。此功能不保证每个项目都能找到案例，也不会自动补齐官方项目资料。

## 开发与资料边界

仓库公开源码与方法说明，但不包含构建所需的完整本地案例库、院校参考库和脱敏 Agent 快照；**仅下载源码无法直接构建与公开 ZIP 相同的安装包**。准备好本地资料后，可在 Node.js 22+ 环境运行：

```powershell
npm install
npm run desktop:build
npm run desktop:test
npm test
```

源数据库中的原始身份信息、用户申请记录、反馈、采集缓存和运行备份不会上传到 GitHub。公开 ZIP 带有经筛选和脱敏的本地资料快照；接收者可以读取其中的数据，分发前仍须复核授权与隐私边界。项目目前未设置开源许可证，未经授权不建议用于商业服务。

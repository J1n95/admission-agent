# 非工科申请分析 Agent 复测（2026-10-18）

## 本轮要验证什么

按用户今天的目标，用当前提示词和本机 DeepSeek Flash API 重测申请分析 Agent，检查金融、传媒、法律、公共卫生、教育、心理六种合成背景能否完成“项目筛选—单项目分析—跨项目排序”，尤其观察案例稀少时如何表达 GPA 位置、不完整经历是否会被误写成主要劣势。该轮是单模型回归测试，不是千问与 DeepSeek 的模型对比。

## 固定场景与调用设计

六位申请人均为合成资料，只使用桌面表单已有字段。每人固定 4 个候选项目，执行 1 次项目筛选、2 次单项目分析、1 次两项目横向排序；共 24 次 API 调用（筛选 6、单项目 12、排序 6）。每一场景都记录 `promptHash`、`inputHash`、`dataHash`，请求内保留相应输入和案例/官方资料快照，以便确认同一场景的资料版本并复跑离线校验。不同阶段的请求结构不同，但申请人、目标项目和本地证据快照保持对应。

## 案例少与空字段的观察

- 教育对照中，2 条案例的港大教育参考值为 58%，10 条案例的港中文教育为 52%；两项都标低置信度、给较宽区间。模型没有给 2 条案例编造 GPA 名次，也明确指出不能据此认定成绩优势或劣势。中心值仍由模型生成，是否合理需要产品负责人判断，不能用“区间较宽”证明它校准正确。
- 公共卫生的 2 案例城大项目为 57%（36–76%），11 案例港大为 63%（44–78%）；前者低置信度、区间更宽，并明确不展示 GPA 名次。
- 心理场景的最终横向结果为 58% 与 54%，两项分别只有 3、2 条案例，均低置信度并使用宽区间；输出指出样本不足以判断 GPA 位置或录取门槛。
- 心理分析将空实习字段表述为“本次未填写/未披露”，并放在材料补充建议和不确定性中；横向排序依据未把它写成“申请人没有实习”。这符合“缺少信息不等于已证实的劣势”的产品边界，但本轮只覆盖一个固定空字段样例。

## 异常、修复与复核口径

24 次调用均收到完整响应，`finish_reason=stop`，没有输出长度截断。首次按当时守门规则验收为 23/24：筛选 6/6、单项目 11/12、排序 6/6。唯一未通过的是理大应用心理单项目分析：模型明确写“不能声称 IELTS 7 满足或超过语言门槛”，语言守门器因为否定词离目标陈述较远而误报，报告数字因此被隐藏。这是确定性校验器的误报，不是模型没生成答案，也不是模型输出截断。

Codex 将否定语境检测扩展到“不能/不应声称、断言、认定”等句式，将该原始输出加入既有 50 条合成边界案例之一，并修改离线最终报告重放器，使其能重新评估被旧规则拒绝的历史输出。定向检查后 50/50 条语言声明规则测试通过；用已保存响应重新验证，旧 24 条输出在当前规则下为 24/24。没有为这次修复再次调用 API，也没有改写原始模型响应。修复的是误判，不应表述成模型能力提升。

## 本轮能说和不能说的结论

可以说：在 6 份固定合成资料、24 次 DeepSeek Flash 请求中，三段流程均生成完整响应；修正一处否定句误报后，当前结构/守门规则离线复核 24/24 通过；六组结果均可按横向参考值降序重放。

不能说：录取预测准确率提升、概率已校准、最优模型已选出、所有专业方向均适用、官方事实与每条引用全部正确，或用户满意度/申请成功率提升。本轮没有真实录取结局、第二模型对照、真实申请人试用，也没有逐条人工核对 24 次响应里的全部项目要求和证据引用。
